# greenden-tailwind
GreenDen – Tailwind CSS Plant Website 🌿

GreenDen is a responsive plant website built using HTML and Tailwind CSS. The website provides a simple and attractive interface for exploring indoor and outdoor plants.

🌱 Features
Responsive navigation bar
Home page with plant collections
Product/plant showcase section
Attractive plant cards with images and names
Responsive design for different screen sizes
Styled completely using Tailwind CSS
Clean and simple user interface
🛠️ Technologies Used
HTML5
Tailwind CSS
JavaScript (if used)
VS Code
📂 Project Structure
greenden-tailwind/
│
├── index.html
├── style.css
├── images/
│   └── plant images
└── README.md
🚀 How to Run
Download or clone this repository.
Open the project folder in VS Code.
Open index.html.
Right-click and select Open with Live Server.
The GreenDen website will open in your browser.
🌿 Project Purpose

This project was created to practice responsive web design and Tailwind CSS, while building a modern plant shopping website interface.
